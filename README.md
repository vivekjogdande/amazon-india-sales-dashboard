# Amazon India Sales Dashboard

## Project Overview
This project analyzes Amazon India sales data to identify sales trends, product performance, customer preferences, and business opportunities using spreadsheet-based data analysis and visualization.

## Objectives
- Analyze overall sales performance.
- Identify top-performing products and categories.
- Understand sales trends and customer purchasing patterns.
- Evaluate order status and fulfillment performance where data is available.
- Present key findings through charts and a dashboard.

## Tools Used
- Microsoft Excel / WPS Office
- PivotTables and PivotCharts
- Data cleaning and analysis
- Dashboard visualization

## Dataset
The project uses the Amazon India sales dataset included in this repository.

## Key Analysis
- Sales performance analysis
- Product and category comparisons
- Order and fulfillment analysis
- Visual representation of business insights

## Repository Contents
- `Amazon Sales Data India_FINAL.xlsx` — project dataset and analysis workbook
- `README.md` — project documentation

## Conclusion
This project demonstrates how sales data can be organized, analyzed, and visualized to support business decision-making.
