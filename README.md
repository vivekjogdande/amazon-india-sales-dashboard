# 🇮🇳 Amazon India Sales Dashboard

### Sales Analytics | Product Performance | Business Intelligence

An Excel-based sales analytics project focused on exploring Amazon India sales data, understanding product performance, analyzing order patterns, and presenting business insights through spreadsheet-based analysis and dashboard visualizations.

---

## 📌 Project Overview

The **Amazon India Sales Dashboard** transforms sales data into structured information that helps analyze sales performance, compare product categories, understand customer purchasing patterns, and examine order fulfillment metrics where the required data is available.

Using Microsoft Excel or WPS Office, this project applies data organization, spreadsheet analysis, PivotTables, PivotCharts, and visual reporting to support data-driven business decision-making.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Identify top-performing products and categories.
- Compare product and category performance.
- Explore customer purchasing patterns where the data supports such analysis.
- Analyze order status and fulfillment performance where relevant fields are available.
- Present important metrics and trends through charts and dashboard visualizations.
- Convert raw sales data into meaningful business insights.

## 🛠️ Tools & Technologies

- **Microsoft Excel / WPS Office**
- PivotTables and PivotCharts
- Spreadsheet formulas and calculations
- Data cleaning and organization
- Sales data analysis
- Data visualization and dashboard design

## 📊 Analysis Performed

### 1. Overall Sales Performance
Analyze available sales metrics to understand the overall performance represented in the dataset.

### 2. Product Performance Analysis
Compare products using available sales measures to identify relatively stronger and weaker performers.

### 3. Category-Wise Analysis
Evaluate product categories to explore differences in sales performance and category contribution.

### 4. Order Status Analysis
Examine order statuses to understand order distribution and order outcomes, provided the relevant fields exist in the dataset.

### 5. Fulfillment Analysis
Explore available fulfillment information to compare order processing or fulfillment patterns where the dataset supports it.

### 6. Dashboard Visualization
Organize key metrics, comparisons, and charts into a dashboard that makes the analysis easier to interpret.

## 📈 Dashboard Components

The dashboard can include the following components, depending on the fields and analyses available in the workbook:

- Total sales and other available KPI metrics
- Product performance comparisons
